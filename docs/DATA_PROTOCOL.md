# 数据统计与集合独立性

公开版使用完整轨迹作为划分单位。同一物理路径的裁剪片段、反向版本、改光照／噪声等衍生版本共用同一个 `trajectory_group_id` 或明确的父轨迹标识，必须留在同一集合。

统计来自原数据规划与归档记录：基础 2,100 对、21 条轨迹，加遮挡 240 对和 ECM 运动 180 对两条独立补充轨迹，共 2,520 对、23 条轨迹、5,040 张原始 RGB。按原始完整轨迹归属，训练 9 条、验证 7 条、测试 7 条。此表描述数据库存及独立划分口径，不是任何既有权重实际见过哪些样本的证明；本包不分发图片、权重或训练运行清单。

时间窗口不能跨序列或时间间隙；保留原始同步时间戳和轨迹身份。相近的姿态范围可以同时存在于不同集合，独立性指来源轨迹，而不是强制让测试姿态超出训练范围。

`stereo_pose/split_policy.py` 检查：

1. `trajectory_group_id`、时间组及记录的父／来源轨迹不能跨集合。
2. 改名后的相同双目图片哈希、同一标签文件或标签内容不能跨集合。
3. 帧数汇总必须与记录一致。
4. 准备和训练入口重新读取原始标签，核验 SHA、split、sequence、group、源帧编号、时间戳和图像／掩码引用。

检查只拒绝错误，不删除样本、重分配集合或自动修正数量。应保留不可变的原始采集标签和规划文件；如果人为同时改写标签、轨迹身份及全部哈希，静态检查不能证明它们原本独立。

标签包括每侧 C、d、H1/H2、J1/J2、T、部件姿态、K/D、关节角、时间和可见性。相机间外参另存为评估真值。遮挡和过曝是合法数据状态，不因为误差大而删除。C/T 不是必须可见的表面点。
