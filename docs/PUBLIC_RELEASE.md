# 公开版本说明

本目录是独立的公开源码版本，原研究目录、原始数据和远端仓库不在本次操作中改写。

保留可复用的模型、运动学、仿真生成、训练／验证／测试／预测入口，以及三张结构图。架构探索文档保留问题、假设、实现和验证方法。性能统计、资源消耗、算子数值一致性和未采用的加速候选继续保留。

发布包不包含已训练权重、历史训练运行目录、训练曲线或当前模型的独立测试精度表。公开训练流程要求从独立轨迹清单开始，运行后才产生该次实验的权重和精度报告。模型结构可以重建；历史速度结果需要同一权重、输入、软硬件环境才能精确重放，这些外部材料未随源码提供。

Git 历史是面向公开源码整理的历史。有效提交尽量保留原有效改动、提交说明和作者；相关运行记录和结果不进入公开历史。历史经过筛选后，受影响提交及其后代的 SHA 会变化。公开提交哈希不应被当成原研究归档的哈希；文档中的历史性能源码／二进制 SHA 是测量时的身份，不代表本次重建。

原始性能数字没有重新测速或修改。`StereoPoseLearning/docs/evidence` 中的公开报告带有原报告 SHA，`report` 内保留执行性能和数值等价性字段；它们不构成独立预测精度证据。图中示例仅说明输入、特征路由和显示接口。

第三方模型、场景、数据和依赖沿用上游许可。获取资产后按来源文档准备，仓库不包含第三方大体积资产。未擅自为第三方文件赋予新的许可证。

提交时间线按公开展示要求重新编排到 2026-11-01 至 2026-11-12，每日 3～6 条，时刻分散在不同时间段。**这些日期为展示编排，不是实际开发／实验日期。** 性能报告中的测量日期保持原记录，不随提交日期重排。

公开历史总数保持 68 条。删除的运行结果记录由本次实际公开版整理、数据接口核验和文档整理提交补齐；不添加空提交来凑数。
