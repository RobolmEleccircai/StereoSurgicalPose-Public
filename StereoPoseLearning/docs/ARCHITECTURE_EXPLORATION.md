# 模型架构探索：问题、实现和验证方法

本文保留模型从全局双目时序回归到前景／部件分支和唯一 C 定位路径的设计过程。它不是精度排行榜，也不提供当前模型的独立测试分数。阶段对照需要固定数据协议、初始化、训练预算和选择规则后重新运行；不能据设计动机断言某个模块已提高泛化精度。

## 1. 阶段总览

| 阶段 | 结构变化 | 当时要回答的问题 | 对应源码 |
|---|---|---|---|
| A：全局双目时序基线 | 共享 ConvNeXtV2/FPN、全局网格 token、跨目注意力、GRU、位姿头/关节头 | 双目与历史信息能否联合输出可解码的器械状态？ | 历史结构设计（见本节说明） |
| B：分割和关键点引导 | 6 个前景/局部 token 替代全局网格；局部关节 GRU | mask 只是辅助任务，还是实际影响 pose 的特征选择？ | 历史结构设计（见本节说明） |
| C：局部 2×2 → 4×4 | 更细局部池化，增加轻量局部编码 | 局部描述是否压缩过度？ | 历史结构设计（见本节说明） |
| D：原图腕部/钳口分支 | 720p 原图前景 ROI；独立腕部和钳口编码/时序/角度头 | 下采样细节损失、背景通路和共享角度头是否构成瓶颈？ | 历史结构设计（见本节说明） |
| E：监督与训练机制整理 | 几何 loss 解耦、直接像素监督、ROI 抖动、采样与持续训练 | 姿态误差是否互相补偿？训练统计和特征路由是否可靠？ | 历史结构设计（见本节说明） |
| F：单一 C 定位来源 | 删除第二套横向位置回归；热图射线 × 学习深度 | 二维定位已经正确，为什么三维 C 又偏了？ | 当前 `stereo_pose/` |

E 是多个已验证工程改动汇合后的冻结状态，不是一项独立单变量实验。F 与 E 的转换有显式权重/优化器映射和零训练步验收。

## 2. A：建立能解释输出的双目时序基线

### 2.1 初始结构

左右目使用同一 ConvNeXtV2 Nano 提取特征，FPN 统一为 128 通道。每目池化为 6×10 网格 token，加入图像位置、视图标识和相机内参/畸变编码，经两层双向跨目注意力融合。每目聚合特征输入 256 维因果 GRU。

位姿头为每目预测 9 个内部数值：3 个位置参数和 6D 旋转；共享关节头从两目的时序状态预测腕俯仰、偏航、钳口半开合。旋转转成矩阵、导出为四元数后，用户接口为 17 个数值。

分割和 C/H1/H2/J1/J2 热图作为辅助输出。固定 CAD 运动学将预测的杆体位姿和关节角变成尖端、铰链及部件坐标轴，再计算三维/二维损失。预训练用于主干初始化，任务层随机初始化后联合优化，不是冻结主干只训练 MLP。

### 2.2 先验证数学与接口

检查旋转正交性、四元数次序、毫米/弧度、左右相机坐标约定、尖端 FK 与独立 NumPy 实现的一致性。改变未来帧不得改变过去输出；逐帧推理与整段前向应一致。测试能证明接口和计算一致，不能证明视觉模型已经学会定位。

### 2.3 暴露的问题

全局网格里有大量组织和背景。辅助分割 loss 下降不意味着位姿头必须依赖器械：主路径仍可从全局 token 读取场景线索。三个关节共用一个压缩表示，也不能保证钳口微小变化被保留。由此提出下一步：让预测分割/关键点真正参与特征路由，而不是只增加分割 loss 权重。

## 3. B：让模型使用器械局部信息

### 3.1 改动内容

新增 `GuidedRegions`：用预测器械 mask 构造前景 token；用五个关键点热图定位 C、H1、H2、J1、J2，各采样一个局部 patch，构成 6 个 token。初版局部池化为 2×2，采样 patch 8×8，半径 24 个定位输入像素，热图幂指数 4。早期背景 floor 为 0.01，后续前景分支版本改为 0。

位姿和关节不再只共用一份全局时序压缩：局部关节特征进入单独的关节 GRU。仍由同一个关节输出头同时预测 pitch/yaw/jaw_half。新增预测热图与运动学投影的一致性项，早期权重 0.1。

### 3.2 为什么这比“把分割权重调大”更具体

分割权重改变辅助目标的重要性；引导 token 改变送入 pose/关节头的信息。两者不同。前者可以使 mask 更好，但无法单独堵住背景旁路；后者至少建立了局部信息进入主预测的明确路径。

### 3.3 实验与边界

冻结权重，在保留器械和周边区域的情况下替换背景，再比较输出变化。诊断中的真值 mask 只用来定义被替换的背景，模型前向仍使用自身预测 mask。这种实验检测背景敏感性，不是部署时使用真值分割。

## 4. C：局部 2×2 改为 4×4，并加轻量处理

### 4.1 假设与具体改动

2×2 池化只保留四个空间位置，可能过早合并铰链和两片钳口的局部关系。保持全局主干、双目融合和时序框架不变，把局部池化改为 4×4，并在局部特征上加入深度可分离的轻量编码层。

此阶段仍处理 FPN 特征，没有重新从原图恢复高频信息。扩大池化网格保留已有特征，不能创造前面下采样已丢失的钳口边缘。

### 4.2 怎样比较

固定初始化来源、数据清单、增强、优化器更新次数和评价精度，按相同训练预算比较；另外列出各自按验证标准选出的检查点。分别统计腕俯仰、偏航、开合及三维位置，不能仅凭一个角度改善就认定所有分支均有收益。

### 4.3 继续诊断后的发现

整体器械分割可能由杆体面积主导；腕部与两尖端的相对关系需要局部检查。即使扩大 FPN 特征池化网格，也不能恢复之前缩小原图时丢失的钳口边缘。下一步因此建立原图观察路径，并分离腕部与钳口处理。

因此下一步针对局部图像入口和角度分支，而不是直接把整个主干加深。

## 5. D：原始 720p 图像上的腕部与钳口分开识别

### 5.1 新的数据流

预测关键点决定两个 ROI：腕部 ROI 包含杆体邻近区域和铰链；钳口 ROI 联合包含两片钳口、铰链和开口间隙。从原始 1280×720 RGB 采样，输出 160×160，而不是裁已经缩小的 640×360 图再放大。

先在原图上应用预测前景 mask，再插值裁剪，防止插值时把周边背景混入前景边缘。mask 阈值 0.2，原图膨胀 1 像素，增加 mask 通道。ROI 位置和用于裁剪的 mask 均 detach；关节 loss 不能靠移动框或掩码形状形成额外编码通路。

腕部分支和钳口分支各有轻量局部编码、双目融合、256 维因果 GRU 及输出头。腕部输出 2 个角度；钳口输出 1 个半开合角。角度分支不再读取全局 FPN token。杆体定位仍需要全图主干，不能因此宣称所有背景信息都已消失。

### 5.2 识别监督

局部分支加入关键点热图监督，监督来自已有 H/J 真值。当前仅有整件器械二值 mask；没有凭空生成“上钳口/下钳口语义 mask”。两片钳口在一个联合 ROI 中预测开合，避免分别识别后仍丢失相互关系。

同时加入在线亮度、颜色、噪声、模糊增强。增强在读取缓存之后执行，并与窗口/双目保持一致。没有用不更新标签的任意图像旋转或弹性扭曲。

### 5.3 结构验证

`test_parts.py` 实际检查：

1. 固定路由后任意改变全局 FPN 输入，关节输出不变，验证没有全局特征旁路。
2. 保持前景及 mask 不变，只改背景，局部裁剪结果不变。
3. 对关节输出反向传播时，腕部/钳口编码、跨目层、GRU、角度头都有有限梯度；被 detach 的路由不会收到这条梯度。
4. 交换尖端/铰链的排列不改变联合 ROI 的范围。
5. 当前和过去输出不依赖未来帧；原图缺失时明确失败，不能静默改用低分辨率图。

这些检查验证实现确实有预期的信息路径，不意味着预测 mask 不会错或遮挡下所有角度均可唯一辨识。阶段 D 同时改变局部分支与增强，若没有相同预算的单因素重训，就不能把总收益全部归给某一个新模块。

## 6. E：处理损失补偿、ROI 稳定性和训练统计

### 6.1 不是简单增加角度权重

冻结网络和输入，分别求直接关节监督、几何和投影损失对输出角度的梯度，再用真值杆体位姿作诊断锚比较方向。该方法用于辨别角度是否在补偿 C／旋转误差；它是离线误差分析，不能将真值锚带入正式推理，也不能单凭输出梯度推断全部网络参数的因果关系。

### 6.2 后续落实的改变

- `decouple_geometry=true`：以真值杆体位姿评价关节几何；以真值关节角评价杆体几何。推理依旧不使用真值。
- `landmark_consistency=0`：关闭把另一个预测热图当作目标的历史项。
- `landmark_uv=1`：直接监督关键点像素位置，保留全局/局部热图监督。
- 训练时 ROI 中心小幅抖动 1 像素、尺度抖动 3%，保持窗口内一致，避免只适应精确裁剪。
- 按轨迹、类别平衡逻辑更新；microbatch 不打乱窗口内部顺序。长轨迹不能仅因窗口多而自动获得更大类别权重。
- 区分 epoch 平均训练 loss、完整验证 loss、逐帧角度与三维误差；不把轮内累计平均误认为每一步 loss。

这些修改汇总于 独立横向回归结构。记录各项配置值和源码身份，明确它是组合版本，不事后虚构每一项都做过完全独立消融。

## 7. F：定位正确但三维 C 偏移，删除第二套横向回归

### 7.1 如何找到问题

尖端误差下降有限时，先用独立 FK 分解 C、杆体旋转和关节角的影响，不能直接把尖端误差全归给钳口。替换 C、只替换光学深度、只替换相机射线等诊断表明横向位置值得重点检查。这些 oracle 替换只用于定位误差来源，不是推理输出。

进一步对比同一帧的两个量：① C 热图的预测像素；② 旧 3D C 经相机模型投影的像素。旧结构由热图完成定位，却又让全连接头独立预测横向位置，两条路径可能不一致。

### 7.2 实现上的根本变化

旧结构：`pose_head → 独立横向参数 + Z + 6D rotation`。

新结构：

```text
C_heatmap → predicted (u,v) → Brown inverse distortion → ray=(x,y,1)
body state + fused C token → positive Z
C = Z × ray
body state → separate 6D rotation head
```

不再保留另一套 X/Y 输出，不增加事后数值修正。训练中 C 位置损失能够沿这条明确路径影响热图和深度。`landmark_consistency` 仍为 0；并非加一个一致性 penalty 掩盖两套横向回归。

### 7.3 结构计算检查

在相同冻结源模型和输入上检查结构变换，确认：

- 共享层和关节输出保持一致，C 只由预测射线与深度得到。
- 旋转正交、深度为正、关节位于固定模型限位内。
- 新深度、旋转和关键点路径能得到有限梯度。
- 原始权重、清单和模型文件保持不变。

随后在同一独立数据协议、相同训练预算下评价结构变更，不将数值一致性当作视觉精度改善。

## 8. 已确定与尚未证明的内容

**尚不能由这些架构实验推出**：新器械泛化、真实内窥镜精度、长时间 C 出画能力、完全遮挡时唯一角度恢复。后续已另行完成4060完整推理加绘图测速，见[性能索引](PERFORMANCE_INDEX.md)；速度以其硬件和计时范围为准，不以几何单元测试或内部低误差代替。

新的结构探索应先冻结源权重、配置、数据清单与评估顺序，再做同预算对照。结果同时保留逐类指标、失败例和退化项。公开目录保留通用诊断工具；重做对照需要各结构自己的权重和冻结运行清单。
