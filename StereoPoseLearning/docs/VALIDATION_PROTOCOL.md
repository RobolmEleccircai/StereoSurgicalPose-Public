# 架构验证与指标解释

验证分成计算正确性、实现契约、受控诊断和训练评估四层。一个层面的通过不能代替另一个层面的证据。文档聚焦架构验证；实际样本身份和运行顺序由不可改写的清单及哈希确定。

## 计算正确性

- 固定器械链：Torch FK 与独立 NumPy `reference/pose_display` 解码比较 C/d/H1/H2/J1/J2/T 和部件旋转。
- 坐标与单位：位置 mm、关节 rad、xyzw 四元数、CV 光学轴；同一帧分别投到各自相机。
- Brown 畸变/逆畸变：数值往返和像素中心缩放一致，旋转验证包括180°及退化6D输入。
- C 射线 × Z：C 的投影与输入射线一致；该结果只说明公式与实现正确，不代表网络像素/深度正确。

## 网络与训练契约

- 改未来帧不改变过去输出；流式与窗口式前向一致。
- 腕部/钳口头使用原图局部特征；固定路由后改变全局输入不影响角度。
- 前景裁剪在插值前屏蔽背景，关键点顺序不改变联合 ROI。
- 每个训练分支有有限梯度；被 detach 的 mask/ROI 路由不会接收角度分支梯度。
- 数据窗口连续，类别/轨迹权重与梯度累积对应；数据预取、共享缓存不更改 RGB、真值或窗口顺序。
- 断点续跑核对源码、配置、资产与清单身份；迁移只改路径，逐张量保留模型/优化器/RNG。
- 无上限训练与学习率日程分开；训练最优和验证最优分别保存，避免只留最新权重。

## 误差定位方法

| 实验 | 保持什么不变 | 改变什么 | 可以回答什么 |
|---|---|---|---|
| 背景替换 | 权重、器械像素及其保护边缘、几何标签 | 背景像素 | 对背景的敏感性；不是全分布因果证明 |
| 时序重置 | 权重、帧序、图像、精度 | GRU 重置边界 | 对历史长度的敏感性 |
| 分量 oracle | 已有预测的其他分量、固定 FK | 一次替换 C/R/某角度 | 哪条误差路径值得检查；改善不可相加 |
| 输出角度梯度 | 冻结网络及输入 | 分别计算 loss 项、可选真值 C/R 锚 | 是否存在角度补偿杆体误差的方向 |
| 热图/三维 C 对照 | 同一次前向、同一 K/D | 比较热图像素与 C 投影 | 是否存在两套不一致的定位来源 |
| 结构转换零步检查 | 同一源权重、输入、目标函数、精度 | 明确映射的新输出结构 | 排除“又多训练了几轮”的混杂 |

oracle 只用于离线诊断；正式预测结果不能用真值修正。固定尖端不可见、组织遮挡和过曝样本保留，不能为降低误差而删除。

## 指标口径

- `position_mm`：两侧 C 的欧氏距离误差。
- `tip_mm`：左右相机中两个实际尖端 J1/J2 的平均欧氏距离，不是中点 T 的误差。
- `hinge_mm`：真实 H1/H2 中心误差。
- `axis_deg`：杆轴方向角误差；不含绕轴自转。
- `rotation_deg`：完整旋转矩阵的相对旋转角，含自转。
- `wrist_pitch_deg / wrist_yaw_deg / jaw_half_deg`：对应关节绝对角误差；总开合角误差不可混写成半开合。
- `projection_px`：当前网络输入尺寸下的像素误差；与原始720p像素比较时必须标注缩放关系。

空间/角度评估按帧计算，先逐类平均，再七类等权汇总。验证 loss 使用重叠连续窗口、与训练相同的损失定义，评估模式不加训练增强。训练 loss 受平衡采样和在线增强影响；因此两条 loss、尖端误差的趋势并不必须一致。逐项 loss 的原始值、权重后贡献和总 loss 分开记录。

## 可重复对照要求

固定权重哈希、源码哈希、配置、数据清单、图像预处理、hidden reset、精度及聚合方式。结构对照须控制其他实验条件，并明确区分实现一致性与预测精度。

数值复现失败应明确报告；相同输入下的实现对照与独立视觉精度评估分开记录。

本公开版不发布当前模型的独立精度结论。论文的 ADD、尖端误差、ROI/整图分辨率、硬件与是否含绘图不同，不能直接比较。速度报告必须以一对双目图为一个时刻，包含预处理、传输、推理、运动学、投影和绘图，并区分纯 GPU 时间和端到端延迟。
