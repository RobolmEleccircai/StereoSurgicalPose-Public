# Agreed two-arrow pose visualization

Yellow projects the segment from C to C+15d (millimeters). Blue projects the segment from C to T. Blue therefore visualizes displacement T−C; T itself remains the camera-frame 3D midpoint of the two physical jaw endpoints. Both arrows start at the same C projection. Labels use thin neutral leaders, not extra vector arrows. No CAD overlay, crosshair or coordinate table is shown.

The blue arrow is dashed when both actual jaw endpoints are labeled tissue-occluded. This is a display convention based on their saved labels, not a surface-visibility claim about virtual T.

All 32 existing stereo pairs were processed using only their original PNGs and JSON truth. All 224 source files remain byte-identical and no renderer was invoked. The annotation report records recomputed C/T projection checks, the two 3D arrow definitions, and all output hashes. Five representative examples are backed up here. These are simulation-ground-truth overlays, not model predictions.
