# Shaft and two physical jaw-tip arrows

The current visualization uses three arrows starting at C: yellow to C+15d in millimeters, blue to physical tip J1, and orange to physical tip J2. J1/J2 are fixed jaw-body identities, not image-left/image-right identities. The virtual midpoint T is not displayed as a replacement tip. Position-indicator arrows represent J1−C and J2−C, while the recorded positions remain in the corresponding camera frame.

Each image shows the saved per-jaw half-opening angle θ and symmetric opening 2θ. Visible physical tip arrows are solid; occluded ones are dashed with their actual self/tissue occlusion type in the label. Closed-jaw endpoints can nearly coincide in projection: colors/widths distinguish the symbols without moving the coordinates.

All 32 pairs were reannotated from saved PNGs and JSON labels. All 224 source data files stayed byte-identical; no renderer was invoked. Five representative pairs are backed up here, with the full annotation report. This is simulation truth, not model inference. The original captures already contain J1, J2 and θ, so no new dataset capture was needed.
